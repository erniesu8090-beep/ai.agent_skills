# Unslop Audit & Polish Guide (舊介面去 AI 味體檢與翻修規範)

> 本指南改編並精簡自 Damir Sokolovsky（[@heydamir](https://x.com/heydamir)）之開源專案 [`heydamir/unslop`](https://github.com/heydamir/unslop)，依 **CC BY 4.0** 授權條款沿用，所有衍生與複製皆應保留此出處署名。

專門處理**已經寫出來的畫面**（React、Tailwind、HTML/CSS 儀表板、App 或 Landing Page），將充滿 AI 樣板感（Vibecoded Slop）的介面，透過「先診斷、定方向、按序重構」的方式翻修為有節制、有產品個性的設計介面。

---

## 與本工作區全域美學規範的搭配原則

1. **從零新建內部工具／儀表板**：色彩與圓角基準優先遵循全域規則第 7 節（暖米白底 `#FAF7F2`/`#F6F4EE`、石墨深炭灰 `#1E2022`、暖灰細線 `#E5E0D5`、`rounded-md`、實體狀態邊條），同時套用本指南的**間距、字級、圖表層級、去 Emoji 與動效限制**。
2. **翻修既有產品或外部專案介面**：尊重專案既有品牌色與主題脈絡，依下方分級流程進行體檢與 9 道 Pass 打磨。

---

## 執行流程（Workflow）

1. **檢視實際畫面（Look at the screen）**：找出渲染該畫面的檔案；若能啟動本地伺服器或開啟 HTML 截圖檢視，務必先看視覺效果而非只讀程式碼。
2. **逐項體檢（Audit）**：對照下方《AI 味破綻速查表》，逐條列出畫面上出現的破綻與所在位置（檔案／區塊）。
3. **分級判定（Decide scope）**：
   - **Heavy slop**（色彩、字體、圖示、文案等多處失控）：執行完整 9 道 Pass。
   - **Light slop**（整體已有設計結構，僅存零星問題）：採用 **Polish 模式**，保留原品牌色、字體、版面與視覺主體，只修復體檢列出的具體破綻；較大的改版構想僅列於報告建議中。
   - **No slop**（介面已經乾淨且一致）：誠實回報無需大改，最多提出 2–3 項精確微調建議供確認，**嚴禁為改而改**。
4. **定下 5 行方向並停下確認（Set direction & Gate）**：修改任何程式碼前，先寫出這 5 行並取得使用者確認（方向一改後面全重做）：
   - **Product**：產品一句話在做什麼、給誰用。
   - **Character**：2–3 個具體氣質詞（如 `calm, exact, warm`；**禁用** clean、modern、sleek、minimal、premium 等空洞字眼）。
   - **World**：產品所屬的材質或場域（筆記本近紙墨、監控工具近夜班儀表板、旅遊近地圖與窗光），用來決定中性色偏與強調色來源。
   - **Moments**：全頁 1–2 個視覺最豐富的焦點（如核心數據圖表、產品內實物預覽），其餘周邊保持安靜。
   - **Signature**：全頁唯一的專屬辨識細節（如即時狀態點、快捷鍵帽、路線折線），只放對的地方，不濫用。
5. **依嚴格順序執行 9 道 Pass**：**每道 Pass 掃完整個畫面後再進下一道**（先調間距才能看清節奏；先改文案才定得下字級與排版；視覺與動效放最後）。
6. **檢查與回報**：跑完文末檢核表並重新預覽比對體檢清單，回報設計方向與每道 Pass 的修改摘要。

## 9 道翻修順序（Nine Ordered Passes）

### Pass 1：Spacing（4px 格線與群組節奏）
- 全部 margin、padding、gap、固定高度對齊 **4px 倍數**（4, 8, 12, 16, 20, 24, 32, 40, 48, 64...）；僅極小元件微調可用 2px，拔除 `mt-[13px]`、`py-[11px]`、`h-[31px]` 等任意數值。
- **密度基準**：元件內部 `4–12`、同清單項目間 `2–8`、群組間 `12–24`、區塊間 `32–64`（Landing 區塊 `80–128`）。
- **列高與內距**：精簡列 `32px`、預設列 `36px`、觸控 `40–44px`；側欄與緊湊面板內距 `16`、卡片 `20–24`、頁面邊距 `24–32`。
- **側欄最易走鐘**：寬度 `240–280px`、導覽列高 `32–36px`（間距 `2–4px`），分類標題「上方 `24px`、下方 `8px`」，確保標題貼近自己的項目。
- **絕對對齊**：同組圖示佔同寬欄位、標籤同一基準線起頭、數字欄靠右對齊；同排兄弟卡片採用一致內距與高度。

### Pass 2：Color（單一中性色階 + 唯一強調色）
- 以產品世界觀選一套微偏色中性色階（如 Graphite 純灰、Warm 暖紙灰、Ink 技術深藍灰），背景、卡片表面、邊框與文字皆出於此色階；App／儀表板表面必須保持中性克制，讓內容承載色彩。
- **文字只留 3 種角色**：`Primary`（主文）、`Secondary`（次要說明）、`Muted`（輔助/標籤，對比度維持近 `4.5:1`），禁止出現五六種相近的淡紫／淡灰字色。
- **全螢幕僅 1 個強調色（Accent）**：只用在主要行動（CTA）、選取態或唯一關鍵數字；文字壓在強調色上須達 `4.5:1` 對比。若已有真實品牌色則沿用為強調色，未經指定不得用紫藍漸層充數。
- **拔除 AI 特效**：禁用色相漸層背景／按鈕、漸層文字、發光陰影（`shadow-[0_0_20px_rgba(...)]`）、背景光斑（blob）、霓虹高對比邊框、白色內高光毛玻璃。
- **深度表現**：邊框改用主文字色 `6–10%` 透明度的髮絲細線（Hairline）。深色主題靠表面色階差與細線分層；淺色主題只用極輕微的中性陰影（`0 1px 2px rgba(0,0,0,0.05)` / 浮層 `0 8px 24px rgba(0,0,0,0.06)`）。

### Pass 3：Icons（單一線性圖示集、清除 Emoji）
- 所有充當導覽圖示、標題裝飾或狀態標記的 Emoji（🚀、✨、📊、⚠️、🔥）一律移除，改為**單一套線性圖示集**（優先專案既有套件，否則統一使用 `lucide`）。
- 全頁維持單一尺寸與線寬（`16px` 或 `18px`，`stroke-width: 1.5`），圖示槽位等寬、與文字固定 `8–10px` 間距。
- 圖示直接繼承 `Secondary` 或 `Muted` 文字色，絕不各自上彩色；無資訊增益的卡片裝飾小圖示直接刪除，分類需求改用小圓點或實體細邊條。

### Pass 4：Copy（去誇張行銷詞、補齊數值參照）
- 拔除介面所有驚嘆號（`!`、`!!`）、招呼語標題（如 `Welcome back! 👋` 改為實際頁面名或時間區間）、短標籤與按鈕結尾句號。
- 刪除空洞行銷詞（`supercharge`、`seamless`、`unlock`、`magic`、`revolutionize`、`AI-powered`），輸入框佔位符精簡（`Search anything...` → `Search`）。
- 變化量必須寫明比較基準（`+12%` → `+12% vs last month`）；未經查證的宣稱（如 `10,000+ teams`）向使用者求證或移除；假資料改為合乎邏輯的真實數值（禁用 `$123,456`、`[X]`）。
- 濫用的 `PRO`、`New ✨`、`Beta 🚀` 徽章刪除，確實必要時改為低調純文字標籤。

### Pass 5：Type（克制字重與數字對齊）
- 介面使用 **1 套無襯線字體**，必要時僅搭 **1 套等寬字體（Mono）** 放數字與 Meta，或 **1 套襯線字體（Display Serif）** 專供大標題（絕不用於標籤或按鈕）。
- **字重鎖在 `400` 與 `500`（極少數重點用 `600`），禁用 `700–900` 厚重標題**；視覺層級靠字級與文字色階拉開，不靠超粗字重。
- 全面使用 **Sentence case（句首大寫）**，禁止全大寫加寬字距標籤（如 `NAVIGATION`、`PAID THIS MONTH`）。
- 16px 以下小字禁用負字距（`letter-spacing < 0` 僅限 40px 以上大標）；禁用斜體作重點強調。
- 所有統計數字與金額強制開啟 `tabular-nums`，且全畫面小數點位數與前綴格式一致（勿 `$48,210` 與 `$124,860.40` 混用）。

### Pass 6：Layout（真實比例與首屏完整）
- 保留產品既有的區塊結構與順序，調整內部分配與比例以提升清晰度。
- App／儀表板應撐滿視窗工作區比例（側欄 `240–280` + 流體內容上限 `1440–1600`），絕不把管理系統縮成窄置中欄。
- Landing 首屏優先採實景圖或非對稱雙欄（文字左、視覺佔至少半寬），避免千篇一律「全部置中堆疊」；僅留 **1 個主按鈕 + 至多 1 個次按鈕**（登入改安靜文字連結）。
- 首屏應成完整構圖（滿屏或產品視圖從底緣延伸邀請捲動），不留大片無意義空白帶。

### Pass 7：Details（嵌套圓角、主次圖表、統計卡淨化）
- **嵌套圓角公式**：`內圓角 = 外圓角 − 內距（padding）`，且下限不低於 `4px`（例：16px 卡片內有 8px padding，內部元件用 8px 圓角）。建議級距：按鍵帽/標籤 `4–6px`、按鈕/輸入框 `8–10px`、卡片 `12–16px`、面板 `14–20px`（勿所有元素都設 `rounded-full`）。
- **圖表有主從**：全畫面僅 **1 張主圖表**佔最大視覺重心（寬度 ≥ 內容區 2/3、高 `280–360px`），另一側配窄列表或精簡表格，禁止並排兩張同等大小圖表；單一強調色標出關鍵系列/當月，其餘採中性階，禁止彩虹長條與發光柱狀圖。
- **統計卡只留數字**：僅放「標籤 + 大數字 + 帶參照變化量」，**拔除硬塞進去的迷你折線圖（sparkline）、計數條或裝飾圖示**；同排卡片避免全頁等寬等高方格，透過「上方 3–4 個精簡統計卡 + 下方 1 張寬主圖表」製造版面節奏。
- **表格與元件狀態**：表格之表頭、使用中數值、選取列與鍵盤焦點（focus ring）須清晰可辨；快捷鍵採按鍵帽樣式，Logo 保持扁平字標或單色符號。

### Pass 8：Visuals（真實產物替代抽象裝飾）
- 刪除 3D 光球、紫色星雲、發光網格、漂浮方塊、發光大腦與機器人插畫。
- 儀表板與工具類畫面幾乎不需要生成圖片，焦點應放在**精心繪製的圖表、排版嚴謹的數據或真實產品內容**（如付款卡物件直接用 CSS 質感呈現）。
- Landing 頁若無實景圖，優先以程式碼打造可信的產品真實預覽（使用真實欄位與合理數據），勿將文字或假按鈕烤進生成圖片中。

### Pass 9：Motion（單一緩動曲線、克制互動）
- 移除無意義循環動畫（非即時資料卻用 `animate-pulse`／`animate-ping`、標題閃光、呼吸光暈、視差捲動與元素飄浮）。
- 禁用 `transition-all`、`hover:scale` 卡片放大與彈跳曲線（spring）；禁止對 `width`、`height`、`top`、`left`、`margin` 做動畫（易卡頓）。
- 僅過渡 `color`、`background`、`border`、`opacity`、`transform`（如 Tailwind `transition-colors`、`transition-[transform,opacity]`）。
- 全站統一單一曲線 `cubic-bezier(0.22, 1, 0.36, 1)`：hover/按壓 `120–180ms`（按壓微縮 `0.97–0.98`）、選單浮層 `160–220ms`、進場至多一次微幅上浮（`6–12px`，`300–500ms`）。

## AI 味破綻速查表（Audit Reference）

| 類別 | 常見 AI 味破綻（Slop Tells） | 對應修正動作 |
|---|---|---|
| **表面與色彩** | 紫藍／紫粉漸層、漸層文字、發光陰影、背景模糊光斑、高對比霓虹邊框、五種相近淡色文字 | 收斂至單一中性色階 + 3 層文字角色 + 1 個強調色；邊框改 6–10% 髮絲線 |
| **字體排版** | 800–900 超粗標題、全大寫寬字距標籤（`NAVIGATION`）、數字格式混用、小字負字距、斜體強調 | 字重降為 400–500、改句首大寫、數字統一 `tabular-nums` 與精度 |
| **圖示與徽章** | 導覽或標題掛滿 Emoji、計數膠囊配 Emoji（`18 👤`）、✨ 標記 AI 功能、到處貼 `PRO` / `New ✨` | 統一單色線性圖示（16/18px, stroke 1.5）或直接移除、徽章改安靜純文字 |
| **間距與元件** | `mt-[13px]` 任意像素、所有按鈕/卡片都用大圓角、統計卡硬塞迷你圖表、同等大小方格排滿畫面 | 嚴守 4px 格線與嵌套圓角公式、統計卡只留數字、建立 1 主圖表 + 次清單節奏 |
| **文案與視覺** | `Welcome back! 👋`、`Search anything...`、`!!`、誇大行銷詞、`$123,456` 假數、3D 球體／發光大腦 | 改為平實產品名詞與頁面標題、補齊比較基準、替換為真實產品介面預覽 |
| **動態效果** | `animate-pulse`、`transition-all`、`hover:scale`、卡片四面八方飛入 | 只過渡色票/透明度/位移，改用單一 `cubic-bezier(0.22, 1, 0.36, 1)` 微互動 |

## 完工檢核清單（Checklist）

- [ ] 已寫出 5 行方向，且所有 Pass 皆服從該方向（未落入千篇一律的純灰模板）
- [ ] 所有間距符合 4px 格線，同類清單／卡片尺寸與內距一致，圖示／標籤／數字各自垂直對齊
- [ ] 僅 1 套中性色階、3 種文字層級、1 個高對比強調色；無漸層文字、光暈或背景光斑
- [ ] 全頁無殘留裝飾用 Emoji；線性圖示單一來源、同尺寸線寬與文字層級同色
- [ ] 字重控制在 400–600、全面 Sentence case、小字無負字距、數字全面 `tabular-nums` 且格式一致
- [ ] 嵌套圓角滿足 `內 = 外 - padding`（且 `≥ 4px`）；按鈕與控制項圓角一致
- [ ] 圖表主次分明、僅用單一強調色；統計卡無多餘裝飾迷你圖；表格四態明確可辨
- [ ] 無 `animate-pulse`、`transition-all`、`hover:scale` 或動畫排版屬性，統一單一緩動曲線
- [ ] **Template Check（抽換測試）**：把產品名稱換成別家產品時，文案、視覺與 Signature 細節是否仍合身？若「完全無違和」，表示個性不夠鮮明，需再強化方向。
